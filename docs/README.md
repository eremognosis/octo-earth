# Octo-Earth technical report

This report documents the simulation as implemented, rather than presenting
the hypothetical mission as present-day engineering. Read the modules in this
order:

1. [Architecture and initial state](architecture.md)
2. [Declared enablers](enablers.md)
3. [Physics and numerical method](physics.md)
4. [Feasibility and practical limits](feasibility.md)
5. [Operations and log interpretation](operations.md)

The participant guide permits up to three declared hypothetical enablers.
Octo-Earth uses exactly three. Every enabled result is conditional on those
assumptions; the no-enabler path remains an intentionally failing physical
baseline.
